# CTF Write-up Template

> Copy this file for every challenge. Save to `writeups/<event>/<challenge>.md`. Link it in the tracker Sheet.

- Event: <event>
- Challenge: <name>
- Category: Web / Crypto / Reverse Engineering / Forensics

- Flag: <flag{...}>
