# CTF Training Notes

Team repository for the 8-week CTF training programme covering **Web, Cryptography, Reverse Engineering and Forensics**.

## Structure
- `cheatsheets/` — quick-reference commands per domain
- `notes/` — the consolidated 8-week plan
- `resources/` — practice platforms, talks, write-up sources
- `writeups/` — challenge write-ups (start from `writeups/template.md`)

## Team roles
- A — Web · B — Crypto · C — Reverse Engineering · D — Forensics

## Rules
- One write-up per member per week, under `writeups/<event>/`
- Log status in the tracker Sheet before each Monday session
- 30-minute timebox before asking the team
